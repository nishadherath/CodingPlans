Not defects, checked and good:

- Arguments survive Windows quoting: quotes, backslashes, `C:\path\`, non-ASCII text, emoji, new lines, tabs, a leading `--help`, double spaces. The fake `agy` got the exact prompt back (`same: true`).
- Timeout: `--timeout 2` gave `timeout`, exit 1, one JSON line, after 2.9 s. The target and a grandchild that held the pipes were both stopped.
- The npm shim route of `resolve` works with spaces in the path and with no `codex.exe` anywhere. New session and `resume` argument orders are accepted by `codex exec --help` and `codex exec resume --help` (`--json`, `--skip-git-repo-check`, `-o`, `-m`, `-c`, `--output-schema` exist on both; `-C` and `-s` are not passed on resume).
- The child gets `HARNESS_DISPATCH_DEPTH=1`. A depth that is not a number refuses with exit 4. Depth 1 with maximum 2 is allowed.
- Every failure path that I tried printed exactly one JSON line with the correct exit code: no output, two JSON objects (the last wins), text before the JSON, two objects on one line, missing or invalid schema file, `--prompt` with `--prompt-file`, an empty stdin prompt, a terminal stdin, an unknown `--cwd`, `--effort max` for Codex.
- The run folder is deleted after each run (0 left after 6 runs).
- Flags against the help texts: `claude --effort` accepts `max`; `--permission-mode manual`, `--permission-prompts none` and `--json-schema` exist. `agy` has `-p` (alias of `--print`), `--mode plan|accept-edits`, `--conversation`, `--effort ... max`, `--json-schema <string or path>`. `agy models` output matches the parser.
- The installer `--target` accepts only known ids, so no path traversal. `--home` is resolved to an absolute path. A folder without the marker is never replaced or removed. The script runs with a lower-case path on Windows.
- The Bash and PowerShell tools of Claude Code give EOF on stdin, so `hd run` without `--prompt` does not hang there.
- The bundle and `bin/harness-dispatch.mjs` gave the same result in the fake-target runs. `node scripts/build-dist.mjs --check`: "bundles are current".
