## Line endings and the `dist/cli.mjs` status

Observed: `git status` showed `dist/cli.mjs` as modified, and `git diff dist/cli.mjs` was empty.
Checked: the working file, the index entry and `HEAD` had the same blob hash (`86b1bb9`).
Cause: the index entry for `dist/cli.mjs` held an old file size (7814 bytes). That size was recorded when the working file had CRLF line endings. The build script now writes LF (it normalises sources, and `.gitattributes` pins `dist/*.mjs` to `eol=lf`). The LF file has 7583 bytes. Git saw a size difference, so it listed the file as modified. It found no content difference. The `.gitattributes` change did not change the committed content.
Correction: `git add --renormalize dist/cli.mjs` refreshed the index entry (size 7583). It staged no content change. `git status` is clean.
Note: the working tree of this repository has CRLF in the text files that Git checks out (the default `core.eol` on Windows). The index holds LF. Git prints "LF will be replaced by CRLF" warnings on each add. The warnings are harmless.
